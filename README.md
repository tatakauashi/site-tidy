# Site Tidy

サイトごとのURL条件とCSSセレクターで要素を非表示にする、Chrome Manifest V3拡張機能です。任意のJavaScript実行、外部通信、解析・広告SDKは含みません。設定は `chrome.storage.local` に保存します。

## インストール

1. Chromeで `chrome://extensions/` を開きます。
2. 「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. このリポジトリーの `extension` フォルダーを選択します。
5. 拡張機能のアイコンから「非表示ルールを設定」を開きます。

## 使い方

1. 設定画面でルール名、対象URL、非表示セレクターを入力し、保存します。
2. 対象サイトを開き、拡張機能のアイコンから「このサイトでの動作を許可」をクリックします。設定画面からホスト名を指定して許可することもできます。
3. 対象ページを再読み込みします。以降は自動適用されます。

ルール例:

```text
ルール名: 広告枠を隠す
対象URL: *.example.com
非表示セレクター:
.advertisement
#ad-area
```

対象要素を右クリックして「検証」を開くと、クラス名やIDを確認できます。セレクターは1行に1つ記入してください。カンマで複数のセレクターを並べることもできます。

ルールのチェックを外すと、そのルールの非表示CSSを取り除きます。サイト本来の `display` を上書きして戻す処理はしません。別のルールでも非表示になっている要素は、そのルールを無効にするまで非表示のままです。編集・削除も開いている許可済みページに反映します。

## URL条件

| 条件 | 対象 |
| --- | --- |
| `*.example.com` | `example.com` とすべてのサブドメイン、全パス |
| `example*.com` | `example.com`、`example123.com` など、全パス |
| `example?*.com` | `example1.com`、`example123.com` など。`example.com` は対象外 |
| `example?.com` | `example1.com`、`examplea.com` など、間にちょうど1文字 |
| `example.com/foo*` | `/foo`、`/foo/bar`、`/foobar` など |
| `https://example.com/foo*` | HTTPSに限定 |

`*` は0文字以上の任意の文字列です。ホスト名では `?` が任意の1文字に一致し、`?*` は1文字以上に一致します。パスの `?` は使用できません（URLクエリとの混同を避けるため）。ホスト名とパスは別々に、文字列全体で一致判定します。スキーム省略時はHTTP・HTTPSの両方が対象です。パスは大文字小文字を区別し、URLのクエリ文字列とフラグメントは判定に含めません。条件にクエリ・フラグメント・ポート番号は指定できません。URLでエンコードされる文字は、URLと同じ表記で入力してください。

## 権限と安全性

- インストール時に全サイトへの恒久的アクセスを要求しません。`activeTab` はアイコンをクリックしたタブのURL確認に使用します。
- 設定画面で許可する場合は指定ホストのHTTP・HTTPS、ポップアップの場合は現在のサイトのスキーム・ホストだけを許可します。Chromeのホスト権限はポート単位では限定されません。
- `*.example.com` のアクセス許可は親ドメインとすべてのサブドメインに及びます。必要に応じて具体的なホスト名を指定してください。
- `example*.com` のような独自URL条件はChromeのホスト権限に変換できません。実際に利用するサイトをそれぞれ許可してください。
- 許可は設定画面から取り消せます。取り消した後は、開いている対象ページを再読み込みしてください。
- CSS宣言やコメントは受け付けず、セレクターの構文を検証します。入力内容をHTMLやJavaScriptとして実行しません。

## 制約

- 通常のHTTP・HTTPSページの最上位ドキュメントが対象です。iframe内部・Shadow DOM内部・Chrome内部ページ・Chrome Web Store等の保護されたページには適用できません。広告のiframeそのものや外側のコンテナーは非表示にできます。
- 後から追加された要素にもCSSが適用されます。SPAのURL変更は最大約750ms後に再判定します（バックグラウンドタブではChromeのタイマー制限により遅れることがあります）。
- ページ読み込み直後、一瞬元の要素が見える場合があります。サイト側のインライン `!important` 等で競合する場合もあります。
- 広告の通信自体はブロックしません。表示を隠す機能です。

## 検証

```sh
node --test tests/rules.test.cjs
```

Chromeで読み込んだ後、対象URLと非対象URL、遅延追加される要素、ルールON／OFF、再読み込み後の再適用を確認してください。
